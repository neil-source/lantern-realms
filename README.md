# Lantern Realms

A single-player browser action RPG built from the pixel-art assets made for Town Raid. It is a separate project, so Town Raid and its save stay untouched.

## Play

```sh
npm start
```

Open <http://localhost:8790>.

## Controls

- Move: WASD, arrow keys, or left stick
- Aim: mouse or right stick
- Attack: Space, mouse, Square, or right trigger
- Talk/open: E, X, or Cross
- Dash: Shift, C, or Circle
- Inventory: B, I, or Triangle
- Map: M, touchpad, or Select
- Pause: Escape, Options, or Start

Progress saves automatically in the browser.
